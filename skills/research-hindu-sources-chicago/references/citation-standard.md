# Chicago Citation Standard for Hindu Sources

Use Chicago Notes and Bibliography. Default to the current Chicago edition unless the user, publisher, or institution specifies another. Preserve complete edition data and use the cited copy’s pagination.

## Core rule

A citation identifies an edition, not an abstract ancient title. “*Manusmṛti* 8.272” identifies a canonical passage; it does not identify the Sanskrit edition, translator, page, publisher, or year. Supply both the canonical locator and edition data.

## Full note templates

### Ancient work in a modern translation

`Traditional Author, *Title*, trans. Translator, ed. Editor, edition statement, vol. X (Place: Publisher, Year), page, canonical locator.`

Example structure only:

`Manu, *The Laws of Manu*, trans. [verified translator] ([Place]: [Publisher], [Year]), [page], 8.272.`

Replace every bracketed field from the cited edition. If authorship is traditional or anonymous, describe it accurately in prose or begin with the title according to the edition and house style.

### Root text with traditional commentary

`Root Author, *Root Title*, canonical locator, in *Edition Title*, with the commentary *Commentary Title* of Commentator, trans. Translator, ed. Editor (Place: Publisher, Year), page.`

Name the commentator and school when interpretation depends upon them.

### Critical or scholarly edition

`Author/Traditional Attribution, *Title*, ed. Editor, series title and number, vol. X (Place: Publisher, Year), page or canonical locator.`

### Chapter or passage in a multivolume epic

`Traditional Attribution, *Epic Title*, book/parvan and chapter, trans. Translator, vol. X (Place: Publisher, Year), page.`

For Mahābhārata and Rāmāyaṇa citations, identify the edition and recension when numbering differences matter.

### Digitized historical book

`Author, *Title*, trans./ed. Contributor (Place: Publisher, Year), page, Digitizing Host, stable URL.`

The original book is the cited work; the host and URL identify the consulted copy. Add an access date when the page is mutable or the required house style calls for it.

### Born-digital scholarly corpus or TEI transcription

`Author/Traditional Attribution, *Title*, ed. or trans. Contributors, version/date (Repository or Project, Year), canonical locator or preserved page, stable URL.`

Add the source print edition after the digital citation when the TEI header identifies it and the claim depends on that edition.

### Project Gutenberg edition

Prefer the original publication facts verified from the ebook. Add the digital host:

`Author, *Title*, trans. Translator (Place: Publisher, Year), canonical locator or preserved page, Project Gutenberg eBook no. N, URL.`

Do not use a plain-text line number as a page. If the Gutenberg file does not preserve pages, cite chapter/section/verse and state that the digital text is unpaginated when necessary.

### Internet Archive scan

`Author, *Title*, trans./ed. Contributor (Place: Publisher, Year), printed page, Internet Archive, stable item URL.`

Use the page printed in the scanned book, not the PDF or viewer image number. If the book has multiple pagination sequences, identify the relevant volume or section.

## Shortened notes

- `Author, *Short Title*, page or canonical locator.`
- `Commentator, *Short Commentary Title*, page or root-text locator.`
- When several editions of the same work occur, include translator/editor or abbreviated edition information sufficient to distinguish them.

## Bibliography templates

### Translated book

`Author. *Title*. Translated by Translator. Edited by Editor. Edition statement. Place: Publisher, Year.`

### Historical edition consulted online

`Author. *Title*. Translated/edited by Contributor. Place: Publisher, Year. Digitizing Host. Stable URL.`

### Digital corpus

`Author/Traditional Attribution. *Title*. Edited by Contributors. Version/date. Repository or Project, Year. Stable URL.`

## Page and locator controls

- Give a page number only if the exact cited edition preserves stable printed pagination.
- Never convert a PDF image number into a book page without checking the printed page.
- Never transfer a page number from another translation or edition.
- Never cite OCR line numbers, terminal line numbers, search-result positions, or browser fragments as book pages.
- When no stable page exists, use the most precise canonical locator available.
- When both are available, give printed page followed by canonical locator.
- For unnumbered digital text, cite chapter/section and identify the text as unpaginated if ambiguity remains.

## Bibliographic controls

- Transcribe title, subtitle, contributor roles, edition, volume, place, publisher, and year from the title and publication pages or authoritative catalogue record.
- Distinguish original publication year, edition year, reprint year, digitization year, and file-update year.
- Do not assign ancient traditional authorship as a modern historical certainty.
- Do not call a translator an author or a commentator an editor unless the edition does.
- Retain diacritics consistently, but do not silently alter the title-page form inside a formal citation.
- For a modern reprint of an old translation, assess the modern editorial layer separately.

## Quotations and translations

- Quote the consulted edition exactly and cite its translator.
- Use ellipses and brackets according to Chicago; do not hide changes in sense.
- Identify direct translations from Sanskrit as the writer’s translation.
- When comparing translations, cite each edition separately.
- If OCR is defective, verify against the scan before quoting. Correct an obvious OCR error only by checking the image and disclose substantive corrections.

## Citation audit record

For research-heavy work, retain a compact record for each citation:

| Field | Required value |
|---|---|
| Claim supported | Exact sentence or proposition |
| Work | Root text or commentary title |
| Contributor roles | Author, commentator, translator, editor |
| Edition | Edition/volume/series |
| Publication | Place, publisher, year |
| Locator | Printed page and/or canonical locator |
| Consulted copy | Stable URL or repository path |
| Verification | Title page checked; cited page checked; OCR checked |
| Rights | License/public-domain/access status |

If any field essential to the requested citation remains unverified, mark it as missing and continue research. Do not guess.
