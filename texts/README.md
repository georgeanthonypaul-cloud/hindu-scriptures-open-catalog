# Mirrored Texts

Only files listed as `approved` in `catalog/mirror_manifest.csv` may appear here. Each payload must retain its upstream license/header and have an adjacent `.metadata.json` file generated by the fetcher.

- `cc-by-4.0/` and `cc-by-sa-*/` contain explicitly licensed Sanskrit or TEI resources.
- `public-domain-us/project-gutenberg/` contains English ebooks that retain the Project Gutenberg notice.
- `public-domain-us/internet-archive/` contains OCR derivatives of identified pre-1931 editions.

Public-domain determinations in this repository are scoped to the United States. Users elsewhere must check local law. An OCR file is not silently treated as a critical edition, and partial coverage is labelled as partial.
